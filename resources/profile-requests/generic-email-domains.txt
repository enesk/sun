# Freemail- und Sammeldomains (SUN-RQ #6).
#
# Eine Absenderadresse auf einer dieser Domains beweist nichts ueber einen
# Betrieb: jeder kann sich dort eine Adresse holen. Deshalb gilt der
# Domain-Match (App\ProfileRequests\Verification\SenderDomainMatcher) hier
# NIE, auch wenn companies.email dieselbe Domain traegt — sonst verifiziert
# `info@gmail.com` jedes Profil mit einer gmail-Adresse.
#
# Eine Domain je Zeile, Kleinschreibung, ohne @. Zeilen mit # sind
# Kommentare, Leerzeilen werden uebersprungen. Die Liste wird mit
# config('profile-requests.verification.freemail_domains') vereinigt; dort
# steht die Grundausstattung, hier die Pflegeliste, die ohne Deployment
# nachgezogen werden kann.
